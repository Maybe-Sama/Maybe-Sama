# Maybe-Sama

**Full-stack developer · AI-powered products**

I build tools where LLMs meet real workflows — terminal streaming, voice agents, applied AI and edtech platforms.

## Selected work

- **[sesigram](https://github.com/Maybe-Sama/sesigram)** — Your terminal, inside Telegram. Streams any CLI session to Telegram in real time; reply from your phone and the input lands back in the running process. Published on PyPI. · `Python`
- **[taichai](https://github.com/Maybe-Sama/taichai)** — AI solver for electrical engineering exercises: paste text or upload a photo, get a step-by-step university-style solution. · `Next.js · FastAPI`
- **[i-m-fine](https://github.com/Maybe-Sama/i-m-fine)** — Arrive-safe web app: browser geolocation + web push to automatically let your loved ones know you made it. · `Next.js`
